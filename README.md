# Sorteat — project website

The companion website for **Sorteat**, a university Human-Computer Interaction team project on reducing household food waste.

**[▶ View the site](https://mariisarbash.github.io/sorteat_website/)**

This site documents the *process*: the project premise, the stage-by-stage course deliverables, and the team behind it. It is the supporting piece — **the prototype itself lives in a separate repository.**

## 👉 Main repository

### **[sorteat_high_fidelity](https://github.com/mariisarbash/sorteat_high_fidelity)** — the high-fidelity React prototype

That repo holds the actual product: shared pantry inventory with expiry tracking and per-flatmate ownership, a split shopping list with a multi-step checkout, and a meal planner that checks every recipe ingredient against what's in stock. Start there.

- **Live prototype (React):** https://sorteat-high-fidelity.vercel.app/
- **Figma prototype:** linked from this site's *"Scopri il Prototipo"* button

## The project

Sorteat was built over five months by a **six-person academic team** as an HCI course project. The process ran from needfinding through to a tested high-fidelity prototype: semi-structured interviews, 2 in-person focus groups, iterative prototyping, a Nielsen heuristic evaluation, and usability testing that produced a final average **SUS score of 89/100**.

**Team:** Mariia Sarbash · Sofia Grumelli · Marco Angelo Ruggieri · Anthony Gerardo Giuliano · Massimiliano Ferretti · Jacopo Ascanio Roncato

**My contribution:** drove the product concept, UX/UI direction and high-fidelity prototype implementation within the six-person team. This website was built by me; the research, evaluation and course deliverables were team work.

## This repository

A hand-written static site — no framework, no build step, no dependencies.

```
index.html      canonical source
stile.css       stylesheet
docs/           what GitHub Pages serves (same page + assets)
└── images/     logo assets
```

GitHub Pages is configured to serve from `docs/`, so `docs/index.html` is the deployed page and the root files are the editing source. Open `index.html` directly in a browser to preview — there is nothing to install or run.

Interface language: Italian.
